# Loan Default Classification

This project uses machine learning to predict whether a loan will default.

## What I used

* Python
* Pandas
* Scikit-learn
* Logistic Regression
* Decision Trees

## What I did

* Loaded and cleaned the loan data
* Selected 500 rows to keep the project simple
* Prepared the data for machine learning
* Trained a Logistic Regression model
* Trained a Decision Tree model
* Compared their performance

## Dataset

The dataset is from Kaggle:

**PS4E9 || Original Data || Loan Approval Prediction** by `rizqi01`

The original dataset contains around 20,000 rows. I used 500 rows for this beginner project.
